# US Entry · 美国入境观察

匿名众包统计中国留学生 / 学者入境美国的情况。网站：https://usentry26.github.io

## 更新数据（维护者）

1. 在腾讯问卷后台导出结果（Excel），放到 `raw/` 文件夹（已被 .gitignore 排除，不会上传）。
2. 在 Excel 里**新增一列，表头写 `公开`**：想在网站上展示其补充经历的行填 `Y`，其余留空。先检查文字里没有可识别身份的信息。
3. 运行：
   ```
   python3 scripts/build_data.py raw/导出文件.xlsx
   ```
4. 打开 `data.json` 快速看一眼，然后提交并推送 `data.json`。

演示数据：`python3 scripts/build_data.py --demo`

## 问卷题目标题要求

脚本按题目标题里的关键词识别列，建问卷时题目标题需包含：

| 关键词 | 题目 |
|---|---|
| 入境日期 | 入境日期 |
| 入境机场 | 入境机场 |
| 签证类型 | 签证类型 |
| 签证情况 | 签证情况 |
| 当前身份 | 当前身份 |
| 专业大类 | 专业大类（STEM / 非 STEM） |
| STEM 小类 / 非 STEM 小类 | 两道小类题，按大类显示其一 |
| 就读过的院校 | 在国内就读过的院校（单选） |
| 学校名称 | 国内就读过的学校名称（必填，多所用顿号分隔，没有填“无”） |
| 入境结果 | 入境结果 |
| 待了多久 | 在小黑屋待了多久 |
| 哪些问题 | 被问到了哪些问题（多选） |
| 手机 | 手机或电脑是否被检查 |
| 停留 | 本次入境前在国内停留了多久 |
| 补充 | 其他经历或补充 |

选项文字以 `scripts/build_data.py` 顶部的列表为准（入境结果需含"直接通过""放行""拒""取消"等字样）。

## 隐私原则

- 网站发布去标识化的逐条记录（用于前端筛选）：入境日期只精确到周，不含学校、ID、自由文本。
- 原始导出只保存在本地 `raw/`，永不提交。
- 补充经历仅在 Excel 里标记 `公开` 后发布，且只附带月份、签证、身份、STEM/非 STEM 等粗略信息，不与逐条记录关联。
- 演示页面：`/?demo`（`python3 scripts/build_data.py --demo --out demo.json`）。
